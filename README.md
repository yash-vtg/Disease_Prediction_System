# Disease Prediction System

A machine learning-based system that predicts the likelihood of two diseases — **Diabetes (Sugar)** and **Cancer** — with an accuracy of **80–90%**. The project leverages Python’s data science ecosystem to build, train, and evaluate predictive models.

---

## 🚀 Features
- Predicts **Sugar (Diabetes)** and **Cancer**.
- Achieves **80–90% accuracy** using machine learning algorithms.
- Built with widely used Python libraries for data science and machine learning.
- Interactive exploration and experimentation via **Jupyter Notebook**.

---

## 🛠️ Technologies Used
- **NumPy** – numerical computations
- **Pandas** – data manipulation and analysis
- **Scikit-learn (sklearn)** – machine learning models and evaluation
- **Jupyter Notebook** – interactive development and visualization

## ⚙️ Installation & Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/yash-vtg/Disease_Prediction_System.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Disease_Prediction_System
   ```
3. Install required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
   *(If `requirements.txt` is not provided, install manually: `numpy`, `pandas`, `scikit-learn`, `jupyter`)*

4. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

---

## 📊 Usage
- Open the notebook file in Jupyter.
- Load the dataset(s).
- Run the cells to train and test the models.
- Input patient data to predict the likelihood of **Sugar** or **Cancer**.
